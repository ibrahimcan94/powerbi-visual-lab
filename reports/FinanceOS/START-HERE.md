# Finance OS - release 2.1.0.0

The current visual contains no bundled sample records and has no sample-data toggle or fallback. It opens in a connection state until your finance ledger is supplied. All five internal pages and their shared filters remain available.

Read Finance-OS-Population-Guide.pdf for the six-page, field-by-field setup guide. In a source checkout, the project includes:

- Finance-OS.pbiviz: generated by running Prepare-Visual.ps1 -Build; build output is ignored by Git.
- FinanceOS.pbip plus Report/SemanticModel folders: one page, one visual, a typed zero-row ledger table with preconfigured field mappings.
- FinanceLedger-Template.csv (and FinanceLedger.csv): headers only, no data rows.
- sample-data/FinanceLedger-Sample.csv: 265 fictional event rows for 120 invoices, provided as an optional example and not loaded by default.
- Connect-FinanceLedger.pq: CSV connection query; change the placeholder file path before using it in the FinanceLedger query.

To populate: prepare one event ledger, open the project, select Transform data and the existing FinanceLedger query, paste the supplied Power Query script in Advanced Editor, change LedgerCsvPath, then Close & Apply. Preserve the table/column names. If using a different report, import the visual and bind the eight required fields described in the PDF. Keep unique EventID and Sum of Amount.

This is an event-ledger visual, not a KPI-measure visual. Provide one Invoice event per invoice plus separate Payment, Credit and optional Promise events. Include full histories, not repeated monthly snapshots. All source rows must use the same reporting currency. Missing optional dimensions show as Unassigned.

The table mapping requests up to 30,000 event rows; host reduction/orphan/malformed-row warnings mean totals must be checked. Cash and ratios use the selected reporting month, while balances use its month-end. Metric definitions and implementation limits are in the PDF and the visual's Metric guide drawer.

The public Creative Tim reference informed the Material-style layout; the implementation uses original React/TypeScript, CSS, SVG and D3 components. The existing KPI visual and earlier Finance report are separate historical projects, not the data source for this empty template.

Source checks, unit tests and production packaging pass. Power BI Desktop refresh, host actions and file/organization policy must be verified in your environment. The PDF contains an illustrative worked reconciliation example. The example ledger is a separate CSV in sample-data/; the model and blank templates contain no rows.
